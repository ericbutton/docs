## Prerequisites

You need an API key with the `api:read` permission. Keys are issued by Enhanced Radar. See [Authentication](/authentication).

<Steps>
  <Step title="Store your API key">
    Keep the key in an environment variable. Never embed it in browser or mobile client code.

    ```bash
    export ER_API_KEY="sk_..."
    ```
  </Step>
  <Step title="Find a facility">
    List the facilities we cover and their channels. Note a `facility_id` and check that its channels have `is_available` set to `true`.

    ```bash
    curl -H "Authorization: Bearer $ER_API_KEY" \
      "https://api.enhancedradar.com/api/v0/facilities"
    ```

    To find a facility by code or name, use [Search facilities](/api-reference/facilities/search):

    ```bash
    curl -H "Authorization: Bearer $ER_API_KEY" \
      "https://api.enhancedradar.com/api/v0/facilities/search?q=san&facility_type=airport&limit=3"
    ```
  </Step>
  <Step title="List transcripts">
    Request transcripts for a time window of up to 48 hours. `since` and `until` are required.

    ```bash
    curl -H "Authorization: Bearer $ER_API_KEY" \
      "https://api.enhancedradar.com/api/v0/transcripts?since=2026-10-22T20:00:00Z&until=2026-10-22T23:00:00Z&facility_id=3667d976-1566-4887-ae34-c024d92f46c7"
    ```

    Transcripts come back newest first. To get the next page, pass `next_cursor` as `cursor` with the same `since`, `until`, and filters.
  </Step>
  <Step title="Get the audio">
    Take an `audio_sample_id` from a transcript and request a short-lived link to its WAV audio. The link expires 3 minutes after the response.

    ```bash
    curl -H "Authorization: Bearer $ER_API_KEY" \
      "https://api.enhancedradar.com/api/v0/transcripts/29e13bdf-08fa-4e44-87a5-ed81a17919a7/audio"
    ```
  </Step>
</Steps>
