<Steps>
  <Step title="Get an API key">
    Create an account to get an API key and 100,000 free credits (\$1,000). You don't need a card.

    **Test keys** return fixed sample data and can't spend credits, so you can build against them safely.

    ```bash
    export ER_API_KEY="your-api-key"
    export ER_API_BASE="https://api.example.com/v1"  # placeholder
    ```
  </Step>
  <Step title="Read transcripts for a flight">
    Pull the radio messages for one callsign over a time window.

    ```bash
    curl "$ER_API_BASE/transcripts?callsign=UAL123&start=2026-10-24T18:00:00Z&end=2026-10-24T20:00:00Z" \
      -H "Authorization: Bearer $ER_API_KEY"
    ```

    Each transcript costs 3 credits (\$0.03). Reading a transcript you already bought is free for 30 days.
  </Step>
  <Step title="Check the charge">
    Each response shows what that request cost. You can also get a free estimate before you run a request. See [Spending controls](/concepts/spending-controls).
  </Step>
  <Step title="Get live updates">
    To have new data sent to you, create a subscription with a webhook URL.

    ```bash
    curl -X POST "$ER_API_BASE/subscriptions" \
      -H "Authorization: Bearer $ER_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "dataset": "transcripts",
        "filters": { "airport": "KSFO" },
        "webhook_url": "https://your-app.example.com/webhooks/enhanced-radar"
      }'
    ```

    See [Pull and push](/concepts/pull-and-push) for how webhooks are delivered and retried.
  </Step>
  <Step title="Set a spending limit">
    Set a hard limit so you never spend more than you planned.
  </Step>
</Steps>
