## Authentication

Send your API key with every request. Test keys return fixed sample data and can't spend credits.

```bash
curl "$ER_API_BASE/transcripts?callsign=UAL123" \
  -H "Authorization: Bearer $ER_API_KEY"
```

## Conventions

- Times are in UTC, in ISO 8601 format.
- Airports are identified by ICAO code, for example `KSFO`.
- Radio frequencies are in MHz, as a decimal string.
- Unknown values are `null` and empty lists are `[]`. Missing facts are never guessed.
- Each response shows what the request cost. See [Spending controls](/concepts/spending-controls).
