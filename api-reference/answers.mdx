Ask a question about selected data, places and dates, and choose the fields you want back. You get an answer with measurements, sources and what's missing. Run it once, or every hour.

## Pricing

You pay for each record checked:

| Records checked | Price per record |
| --- | --- |
| First 1,000 | 2 credits ($0.02) |
| Next 4,000 | 0.25 credits ($0.0025) |
| After 5,000 | 0.04 credits ($0.0004) |

So 1,000 records cost $20, 5,000 cost $30 and 50,000 cost $48.

- Each answer costs at least **300 credits ($3)**. If less than that is available, we skip the run.
- Each answer has a spending limit. The default is **5,000 credits ($50)**, and you can change it. Your balance and account limit also apply.
- If a run stops early, you pay for the records read and get a partial answer.
- Every new run is charged, even if the answer didn't change. Reading a saved answer and retries are free.
- Reading sources is included. Full downloads and audio cost extra.

## Save an answer

<div className="not-prose">`POST /answers`</div>

<Note>Field names are placeholders until the v1 OpenAPI spec is final.</Note>

<ParamField body="question" type="string" required>
  What you want to know, in plain language.
</ParamField>
<ParamField body="sources" type="object" required>
  The data to check: datasets, places and dates.
</ParamField>
<ParamField body="fields" type="array">
  The fields you want back in the answer.
</ParamField>
<ParamField body="schedule" type="string">
  Set to `hourly` to run every hour. Leave out to run only on request.
</ParamField>
<ParamField body="webhook_url" type="string">
  Where to send each scheduled answer.
</ParamField>
<ParamField body="spend_limit" type="number" default="5000">
  The most a single run can spend, in credits.
</ParamField>

## Run an answer now

<div className="not-prose">`POST /answers/{id}/runs`</div>

Runs a saved answer once and returns the result.

## What it costs

Hourly is 8,760 runs a year.

| Example | Records per answer | Per answer | Per year, hourly |
| --- | --- | --- | --- |
| Flight delays | 10 transcripts | $3 (minimum) | $26,280 |
| Airport changes | 1,000 | $20 | $175,200 |
| Delays across airports | 10,000 | $32 | $280,320 |
